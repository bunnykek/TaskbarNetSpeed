# Changelog

All notable changes to TaskbarNetSpeed are listed here.
Versions follow [Semantic Versioning](https://semver.org): MAJOR.MINOR.PATCH.

## [1.0.0] - 2026-10-22

### Added
- Live upload and download speed on the Windows 11 taskbar, with a transparent background.
- Speed units: Auto (KB/s, MB/s), KB/s, MB/s, Auto (Kbps, Mbps), Kbps, Mbps.
- Left-drag to move along the taskbar; Reset position.
- Start with Windows option.
- Text colour follows the light or dark taskbar theme.
- Hides during full-screen games and videos.
- Builds for x64, x86 and ARM64.
- Version shown in the right-click menu and in the .exe file properties.
